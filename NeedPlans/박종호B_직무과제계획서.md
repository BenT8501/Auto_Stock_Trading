# 직무 과제 계획서

## 1. 업무명

Unreal Engine 기반 기존 Project_Z의 소규모 FPS 멀티플레이 기능 설계 및 구현

## 2. 배경 및 목표

### 배경

Unity 멀티플레이 개발 경험을 기반으로 Unreal Engine 프로젝트 파견 업무를 수행하기 위해서는 엔진 주요 기능의 동작 방식과 클래스별 역할을 이해하고, 담당 기능의 처리 흐름과 설계 의도를 팀원에게 명확히 설명할 수 있어야 합니다. 이에 기존 Project_Z에 멀티플레이 기능을 추가하여 Unreal의 게임플레이 구조와 네트워크 처리에 대한 이해를 높이고, 구현 내용을 근거로 기술적 의사소통 역량을 강화하고자 합니다.

### 목표

기존 Project_Z의 맵과 게임플레이 기능을 활용하여 최대 6명이 참여하는 2팀 FPS 샘플 프로젝트를 구현합니다. Listen Server 기반으로 접속, 이동, 발사, 피격, 사망, 리스폰 등의 핵심 플레이 흐름과 팀 배정·팀별 스폰 및 접속 인원 관리를 구현합니다.

주요 클래스의 역할과 서버·클라이언트의 책임을 구분하고, 상태의 저장 위치와 수명을 설계합니다. 다중 클라이언트 및 지연·패킷 손실 환경에서 동작을 검증하고, 설계 의도와 발생한 오류의 원인 및 수정 내용을 설명할 수 있는 수준의 역량 확보를 목표로 합니다.

## 3. 기대효과

- 클래스별 역할과 데이터 흐름을 파악하여 기능의 구현 위치와 변경 영향 범위를 검토하고, 기능 수정 및 추가 업무에 대한 대응 능력을 강화합니다.
- 설계도와 실제 코드의 실행 흐름을 근거로 구현 의도와 동작을 설명하여 팀원과의 기술적 의사소통을 개선합니다.
- 멀티플레이 오류의 재현, 원인 분석, 수정 및 재검증 경험을 확보하여 문제 해결 능력을 향상합니다.
