# 직무 과제 계획서
1. 업무명
- Unreal Engine기반 소규모 FPS 멀티 플레이 샘플프로젝트 설계 및 구현
2. 배경 및 목표 (해당 직무과제가 왜 필요한지 진행 배경과 직무과제를 통해 달성하고자 하는 목표 작성)
배경 
Unity 멀티 플레이 개발 경험을 기반으로 Unreal Engine 기반 프로젝트 파견 업무를 수행 하기 위해서는 엔진 주요 기능의 동작 방식과 클래스별 역할을 이해하고, 담당 기능 처리 흐름과 설계 의도를 팀원에게 명확히 설명 할 수 있어야 합니다. 이에 독립적인 FPS 멀티 플레이 프로젝트를 설계, 구현 하여 Unreal의 게임 플레이 구조와 네트워크 처리에 대한 이해를 높이고, 구현 내용을 근거로 기술적 의사 소통 역량을 강화 하고자 합니다. 

목표
최대 6명의 참여하는 2팀 FPS  샘플 프로젝트를 제작 하고, 접속, 이동, 발사, 피격, 사망, 리스폰 등의  핵심 플레이 흐름을 구현합니다. 주요 기능 별 클래스의 역할과 서버 클래스의 역할, 상태의 저장 위치와 수명을 설계 하고 구현합니다. 다중 클라이언트 및 지연 환경에서 동작을 검증하고, 발생한 오류와 원인, 수정 내용을 설명 할 수 있는 수준으로 역량을 끌어 올리는 것을 목표로 합니다.

3. 기대효과 (업무 완수 시 조직/지원업무에 기여하는 바 – 구체적인 기대 성과)
클래스별 역할과 데이터의 흐름을 파악 하여, 담당 기능의 구현 위치와 변경에 따른 영향 범위를 검토 하여 기능 수정 및 추가 업무 대응 능력을 강화 합니다.
설계도와 실제 코드의 실행 흐름을 근거로 구현의도와 동작을 설명하여 타 팀원과의 협업 시 기술적 의사 소통을 개선 할 수 있습니다.
멀티 플레이 오류 원인 분석 및 오류 수정을 경험을 확보 하여 문제 해결 능력향상을 확보 할 수 있습니다.
