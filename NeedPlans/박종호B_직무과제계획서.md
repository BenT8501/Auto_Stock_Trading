# 직무 과제 계획서

## 1. 업무명

Unreal Engine 기반 기존 Project_Z의 소규모 FPS 멀티플레이 기능 설계 및 구현

## 2. 배경 및 목표

### 배경

Unity 멀티플레이 개발 경험을 기반으로 Unreal Engine 프로젝트 파견 업무를 수행하기 위해서는 엔진 주요 기능의 동작 방식과 클래스별 역할을 이해하고, 담당 기능의 처리 흐름과 설계 의도를 팀원에게 명확히 설명할 수 있어야 합니다. 이에 기존 Project_Z에 멀티플레이 기능을 추가하여 Unreal의 게임플레이 구조와 네트워크 처리에 대한 이해를 높이고, 구현 내용을 근거로 기술적 의사소통 역량을 강화하고자 합니다.

### 목표

기존 Project_Z의 맵과 게임플레이 기능을 활용하여 최대 6명이 참여하는 2팀 FPS 샘플 프로젝트를 구현합니다. Listen Server 기반으로 접속, 이동, 발사, 피격, 사망, 리스폰 등의 핵심 플레이 흐름과 팀별 스폰 및 점수 처리를 구현합니다.

주요 클래스의 역할과 서버·클라이언트의 책임을 구분하고, 상태의 저장 위치와 수명을 설계합니다. 다중 클라이언트 및 지연·패킷 손실 환경에서 동작을 검증하고, 설계 의도와 발생한 오류의 원인 및 수정 내용을 설명할 수 있는 수준의 역량 확보를 목표로 합니다.

## 3. 기대효과

- 클래스별 역할과 데이터 흐름을 파악하여 기능의 구현 위치와 변경 영향 범위를 검토하고, 기능 수정 및 추가 업무에 대한 대응 능력을 강화합니다.
- 설계도와 실제 코드의 실행 흐름을 근거로 구현 의도와 동작을 설명하여 팀원과의 기술적 의사소통을 개선합니다.
- 멀티플레이 오류의 재현, 원인 분석, 수정 및 재검증 경험을 확보하여 문제 해결 능력을 향상합니다.

## 4. 업무일정

**전체 일정: 5주 / 25근무일 — 개발 및 통합 검증 4주 + 최종 정리 및 시연 준비 1주**

기존 Project_Z의 맵, 캐릭터, 무기, 아이템, 애니메이션 등 구현된 기능을 재사용하는 것을 전제로 합니다. 멀티플레이 기초 학습은 별도 주차로 분리하지 않고 각 기능의 설계·구현 과정에 포함합니다. 1주차에 기존 구현 상태를 확인하여 미구현 부가 기능은 범위를 조정하고, 접속·전투·팀 배정·리스폰을 우선 확보합니다.

| 주차 | 주요 작업 | 기간 | 완료 기준 및 산출물 |
|---|---|---|---|
| 1주차 | 기존 구조 분석, 네트워크 역할 및 상태 배치 설계, 접속·이동·충돌·기본 상태 동기화 | 5일 | 2인 접속 및 이동 확인, 클래스 역할도와 상태 배치표 |
| 2주차 | 서버 발사 검증·명중·피해 처리, 기존 방어구·반동·연출 연동, 체력·탄약·HUD 동기화 | 5일 | 2인 전투 결과 일치, 발사·피격 처리 흐름도 |
| 3주차 | 재장전·취소·중복 요청 처리, 사망·리스폰, 팀 배정·팀별 스폰·킬/데스·팀 점수 | 5일 | 최대 6명 팀전 핵심 흐름 구현, 상태 초기화 및 유지 항목 정리 |
| 4주차 | 접속·퇴장 및 6인 검증, 지연·패킷 손실·충돌·전투 테스트, 오류 수정 및 재검증 | 5일 | 시연 대상 기능 확정, 통합 테스트 결과와 오류 수정 기록 |
| 5주차 | 설계·검증 문서 최종 정리, 시연 빌드 및 영상 준비, 리허설 | 5일 | 최종 빌드, 기술 설명 자료, 시연 시나리오 및 예비 영상 |

### 적용 범위 및 일정 관리 기준

- 기존 맵을 활용한 최대 6명, 2팀, Listen Server 방식의 멀티플레이를 대상으로 합니다.
- 시연에 필요한 호스트 실행 및 클라이언트 접속 경로를 확보합니다. 별도 방 목록·로비 UI, 계정, 랭킹, 자동 매칭, 전용 서버 운영은 제외합니다.
- 외부 인터넷 접속이 필요한 경우 1주차에 접속 방식과 시연 환경을 확정하고 일정 내 구현 가능 여부를 확인합니다.
- 설계 근거, 테스트 결과, 오류 원인 및 수정 내용은 매주 기록하고 5주차에 최종 정리합니다.
- 신규 기능 구현은 4주차까지 완료하며, 5주차는 시연 준비와 시연을 방해하는 오류 수정에 사용합니다.
