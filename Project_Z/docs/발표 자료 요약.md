4. 발표 직전 최소 복습 질문
a. Character, Enemy, GameMode는 각각 무엇을 담당하는가?
- Character는 Player Character의 이동, 공격, 조준, 탄약수등을 담당한다.
- Enemy는 Player Character 인식, 추적, 공격 AI등을 담당한다. 
- GameMode는 게임의 시작, 게임 오버, 스테이지 클리어등 전반적인 게임 규칙을 담당한다.
b. WeaponDataAsset과 ProjectileDataRow는 어떤 데이터를 정의 하는가?
- 무기 종류별 데이터를 정의 한다. 예를 들어 샷건은 발사되는 탄환수, 공격력, 탄환 속도 등을 정의 한다.
- ProjectileDataRow 발사체의 기본 데이터로 기본데미지, 초기 탄속, 최고 탄속, 생명주기, 충돌 반경등을 정의한다.
c. AvailableActor와 InUseActors는 무었이 다른가?
- AvailableActor는 사용 대기 중인 발사체 actor를 말하고, InUseActors는 이미 사용 중인 발사체 Actor를 모은 배열들이다.
d. RuntimeHitActor는 왜 재사용 전에 비워야 하는가?
- 해당 배열에 들어있으면 다음 발사시 충돌처리에서 제외 되기 때문인다.
e. HP, Damage, CurrentHP는 무엇이 다른가?
- Attribute::HP GAS가 관리하는 현재 채력, 플레이어 뿐아니라 Enemy에도 같은 방식 적용 한다. Attribute::Damage 피해량을 처리 하기 윈한 임시 Attribute 값을 읽고 0으로 초기화 하며 읽은 피해량으로 HP 값을 차감 한다.
AZEnemyBase::CurrentHP Enemy가 별로로 보관 하는 체력, 사만판정등에 사용 하고 Attribute::HP와 이중 관리되고 잇어서 현재는 수정 됨
f. Data.Damage와 SetByCaller는 어떻게 연결 되는가?
- Data.Damage는 피해 수치를 전달 할 때 사용 하는 GameplayTag 키 이다. SetSetByCallerMagnitude()로 EffectSpec에 이 키와 최종 피해량을 설정 한다. GamePlayerEffect에 Modifer가 같은 키의 SetByCaller를 사용 하도록 설정 해야 한다.
g. FinishReload는 누가 언제 호출 하는가?
- Relaod Montage Animation Blueprint에서 해당 애니메이션이 거의 끝날때 Notify로 호출한다.
h. AliveEnemyCount는 언제 증가 하고 감소 하나?
스테이지가 시작 할때 SpwanAllEnemise()함수에서 EnemyActor가 생성 될때 증가한다.
Enemy Actor가 죽을 때 OnDie() 함수에서 감소 한다.
i. HUD의 HP, 경험치 탄약등은 각각 어디에 저장 되는가?
HP는 Player AttributeSet, 경험치는 CharacterBase의 CurrentExperience, 탄약도 CharacterBase의 CurrentAmmo에서 저장한다.
