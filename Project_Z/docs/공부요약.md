    1. 필수 클래스와 구조체
    	a. AZCharacterBase
    		i. 플레이어 이동 , 조준, 무기, 탄약, 재장전등 플레이어 행동과 전투 실행을 담당
    	b. AProject_Z_PlayerController
    		i.  플레이어 제어, UI 입력 모드 관리 캐릭터와 별개로 플레이어의 제어와 화면 흐름을 관리한다.
    	c. AProject_Z_GameMode
    		i. 스테이지 진행, 적 생성, 게임 클리어, 게임 오버등 게임진행 규칙을 담당한다.
    	d. AZEnemyBase
    		i. 적 탐색, 추적, 공격, 피격, 사망등 적 행동과 전투 상태를 관리 한다.
    	e. AZProjectileBase
    		i. 투사체 이동, 충돌, 피해, 반환 등 투사체의 동작을 담당한다.
    	f. UZActorPoolSubsystem
    		i. 투사체 Actor 획득, 재사용, 반환등 World 수명에 맞춰 Pool을 관리 한다.
    	g. UZWeaponDataAsset
    		i. 무기별 설정 정의등 공통 발사 로직에서 사용할 무기별 수치를 보관 한다.
    	h. FProjectileDataRow
    		i. 투사체 DataTable의 행 구조체로 투사체의 기본 설정의 항목과 자료형을 정의 한다.
    	i. UZGA_PrimaryAttack
    		i. GAS 기본 공격 Ability로  Ability Component활성화를 캐릭터의 무기 사용으로 연결 한다.
    	j. UZAttributeSet
    		i. HP, Stamina, Damage 등 GAS속성을 보관 하고 피해에 따른 각 속성의 변경을 처리 한다.
    		ii. 플레이어와 적은 같은 UZAttributeSet클래스를 사용 하지만 각각의 별도의 인스턴스 값을 가진다.
    	k. UZAnimNotify_ReloadAmmo
    		i.  탄약 보충 Notify로 지정된 시점에서 탄약 보충을 위한 FinishReload를 호출 한다.
    	l. UZHUDWidget
    		i. 전체  HUD 구성 이다. 상태, 조준점 상호 작용 위젯을 묶은 부모 HUD이다.
    	m. UZStateHUDWidget
    		i. 상태 정보 표시, 캐릭터의 정보를 Getter로 값을 읽어 화면에 출력 한다.
    2. 필수 변수들
    	a. 무기 관련 변수들
    		i. currentAmmo - 캐릭터의 현재 탄환 수
    		ii. BaseDamage - 무기 기본 피해량
    		iii. runtimeProjectileDamageBouns - 실행 중 투사체 피해량 보정
    		iv. ProjectileDamageMultiplier - 투사체 피해량 배율
    		v. ProjectileSpeed -  투사체 속도
    		vi. Range -  무기 사거리
    		vii. Cooldown - 공격 간 대기 시간
    		viii. ProjectileClass - 풀에서 가져올 투사체 클래스
    		ix. ProjectileRowName - 투사체 DataTable에서 읽을 행의 이름
    		x. FirePattern - 발사 패턴값, Single, Spread, Pierce 값을 가지는 영거형 타입
    		xi. ProjectileCount - 한번에 발사에 사용할 발사체 수
    		xii. SpreadAngleDegrees - 확산 각도
    		xiii. FiredProjectileCount - 발사 성공한 발사체 수 (지역변수)
    		xiv. FireDirection -  개별 발사체 방사 방향
    		xv. SpawnTransform - 위치, 회전등 배치 정보
    	b. Pool과 투사체 상태
    		i. AvailableActors - 재사용을 기다리는 Actor 목록
    		ii. InUseActors - 현재 사용 중인 Actor 목록
    		iii. ActorToPoolClass - Actor가 어느 클래스의 풀에 속하는지 찾는 맵핑
    		iv. RuntimeHitActors -  이번 발사에서 이미 명중한 actor 기록
    		v. RuntimeDamageOverride - 기본 피해량 대신 사용 할 런타임 피해량
    		vi. LifeTimerHandle - 투사체 수명 타이머 관리 핸들
    		vii. ReturnDistance - 발사체 반환 거리
    		viii. RemovedCount - 사용자 목록에서 실제 제거한 개수, 중복 반환 방어를 위한 지역 변수
    	c. 체력 , AI, Stage
    		i. AttributeSet -  GAS 속성, HP, Ammo등 있다
    		ii. TargetPlayer - 적이 탐지 대상으로 삼는 객체
    		iii. TargetDetectionRange -  적이 탐지 거리
    		iv. TargetDetectionAngle - 적 탐지 시야각
    		v. AttackRange - 공격 가능 거리
    		vi. bIsInCover - 플레이어 엄폐 상태
    		vii. bIsDead -  적 사망 상태
    		viii. AliveEnemyCount - 살아있는 적 수

3. 핵심 함수와 호출 흐름
	a. 공격 입력과 발사
		i. OnAbilityInputPressed()
		->  TryActiveAbility()
		-> UZGA_PrimaryAttack::ActiveAbility()
		-> FirePrimaryProjectile()
		-> AcquireProjectile()
		-> LaunchInDirection()
		ii. BindAction()로 바인딩 된 입력 이벤트를 받아 Ability를 부여 한다. TryActiveAbility() 함수로 부여된 ability의 활성화를 시도한다. ActivePrimaryWeapon() 에서 FirePrimaryProjectile() 함수로 발사체를 준비 하고 발사 한다.
	b. 충돌과 처리
		i. HandleProjectileOverlap()
		-> ApplyGamePlayDamage()
		-> SetSetByCallerMagnitude()
		-> ApplyGameplayEffectSpecToTarget()
		-> PostGameplayEffectExcute()
		-> SyncHealthFromAttributeSet()`
		ii. 발사 시 무기 데이터와 런 타임 보정으로 피해량을 설정 하고, 명중 시 해드샷(GAS 값 추가 데미지) 배율을 반영한다.
			EffectSpec에 피해량을 전달 하기위한 키로 Data.Damage를 설정 한다.
			PostGamePlayEffectExcute()에서 Damage를 사용 하여 HP를 차감한다.
			이후 SyncHealthFrmoAttributeSet() 함수에서 적 HP를 계산 하여 사망 여부를 판단한다.
c. 재장전
	i. Reload()
	-> PlayReloadAnimaion()
	-> Montage_Play()
	-> UZAnimNotify_ReloadAmmo::Notify()
	-> FinishReload()
	-> SetCurrentAmmo()
	ii. 몽타주 재생중 특정 시점에 Notify보내고 SetCurrentAmmo()함수에서 갱신한다.
d. HUD
	i. NativeTick()
	-> RefreshCurrentStatus()
	-> Character -> getter
	-> UpdateHP() / UpdateAmmo()
	ii. TickUpdate에서 캐릭터의 getter이용 화면을 갱신한다.
e. 스테이지
	i. StartTPSStage()
	-> SpawnAllStageEnemise()
	ii. 시작 함수에서 적을 모두 스폰 한다.
