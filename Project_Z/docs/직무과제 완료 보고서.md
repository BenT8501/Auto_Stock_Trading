3. 성과 (기대효과 대비 달성한 내용 작성)
기존 Unity 멀티플레이 개발 경험을 Unreal의 서버 RPC·Replication·RepNotify에 적용하여 팀 FPS를 구현했습니다. 호스트와 게스트의 동작 차이를 입력·서버 검사·값 변경·복제·화면 표시로 나누어 확인하고 수정하는 방법을 익혔습니다.
GameMode·GameState·PlayerState·PlayerController·Character에 팀 선택·전투·리스폰을 구현하며, 클래스별 기능과 데이터 배치, 사망 후 유지할 값과 초기화할 값을 판단하는 경험을 쌓았습니다.
무기 데이터와 공통 전투 처리를 활용해 무기 교체·쉴드·아이템 기능을 확장하고, 서버의 상태 변경을 UI·애니메이션에 연결하는 능력을 높였습니다.

아키텍처
C++에서 서버 요청·검사·상태 복제 구현, Blueprint·에셋에서 메시·애니메이션·무기 설정 적용
• MultiPlayerController: 팀 선택을 서버 RPC로 요청, 소유 플레이어의 위젯 생성·전환 및 입력 모드 설정
• MultiGameMode: 서버에서 팀 승인·스폰·리스폰·처치 점수 등록·경기 종료 처리
• MultiGameState: 서버의 팀 점수·남은 시간·경기 단계·승리 팀을 클라이언트에 복제
• MultiPlayerState: 서버에서 소속 팀 저장·복제, 일반 리스폰 후 팀 유지
• ZCharacterBase: AbilitySystemComponent·AttributeSet 생성, BeginPlay에서 Ability Actor 정보 초기화, HP 등 속성 조회 함수 제공
• ZCharacterBaseMulti: Base 상속, 서버 RPC로 발사·무기 습득 요청 수신, 서버에서 발사·탄약·재장전·피해·사망 처리 및 전투 상태 복제
• ZCharacter_FPS: Multi 상속, 로컬 FPS 입력·카메라·조준 표현, 달리기·재장전 요청을 서버 RPC로 전달
• ZCharacter_TPS: Multi 상속, 기존 TPS 조작·카메라·표현 유지
• Projectile: 서버에서 이동·충돌·피해 처리, 복제된 이동·활성 상태를 각 클라이언트에 반영
• ActorPoolSubsystem: 서버 발사체 획득·반환·재사용 관리
• WeaponDataAsset: 무기 기본 설정 보관, 현재 무기·탄약·쉴드 등 변경값은 캐릭터에서 복제

네트워크 처리 흐름
로컬 입력 → 서버 RPC 요청 → 서버 조건 검사·상태 변경 → Replication으로 상태 전달 → 클라이언트 HUD·캐릭터 표현 갱신
공격·재장전 애니메이션은 Multicast로 전달하고, 탄약·쉴드·사망 여부 등 현재 값은 변수 복제로 전달




5-1. 아키텍처 구현을 통한 역량 향상

수행 내용
• 팀 선택·발사·재장전·무기 습득 요청을 서버 RPC로 전달하고 서버에서 실행 조건 검사
• 서버 전용 GameMode에서 팀 승인·스폰·경기 진행, GameState·PlayerState를 통해 경기 정보·팀을 클라이언트에 전달
• 서버의 탄약·쉴드·사망 상태를 복제하고, 클라이언트에서 HUD·무기·애니메이션 갱신
• 일반 리스폰 시 PlayerState의 팀은 유지하고 새 Pawn의 HP·탄약·쉴드 초기화
• 클라이언트에 팀 정보와 Pawn이 준비된 뒤 HUD·게임 입력으로 전환

향상된 실무 역량
Unreal의 서버·클라이언트 실행 위치와 RPC·복제 경로를 구분한 멀티플레이 구조 설계 능력 향상
서버에서 변경할 값·클라이언트에 전달할 값·리스폰 후 유지할 값을 구분한 네트워크 데이터 배치 능력 향상

주요 클래스 및 함수
• AProject_Z_MultiGameMode: TrySelectPlayerTeam(), RestartPlayer(), RegisterPlayerKill()
• AProject_Z_MultiGameState: TeamAScore, TeamBScore, MatchPhase
• AProject_Z_MultiPlayerState: PlayerTeam, OnRep_PlayerTeam()
• AProject_Z_MultiPlayerController: RequestTeamSelection(), CreateHUDWidget()
• AZCharacterBaseMulti: 공통 전투·재장전·피해·사망
• AZCharacter_FPS: FPS 입력·ADS·무기 습득·마커 표시

팀 입장 흐름
로컬 팀 UI → Controller 서버 RPC → 서버 GameMode 검사·승인 → PlayerState 팀 저장·복제 → 서버의 팀 주변 스폰·Possess → 로컬 팀·Pawn 준비 확인 → HUD·게임 입력 전환
※ 공간 부족 시 대기열 등록 후 기본 0.5초 간격 재탐색
