# Project Context

This project builds a Python-based stock trading research system.

Scope:

- Phase 1: local CSV backtesting only
- Phase 2: paper trading monitor
- Phase 3: live trading only after separate approval and safety review

Target universe:

- S&P 500 top 100 companies
- KODEX 200-related Korean market top 80 universe

Non-negotiable rule:

- AI tools may assist development and review, but a human must approve any move toward live trading.
